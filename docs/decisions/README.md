# Registros de decisões arquiteturais

Este diretório contém ADRs (*Architecture Decision Records*): registros curtos
das decisões técnicas que afetam o projeto por longo prazo.

## Convenção

Os arquivos usam numeração sequencial e um título curto:

```text
0001-processo-hibrido-de-documentacao.md
0002-nome-da-proxima-decisao.md
```

Cada ADR possui contexto, decisão, alternativas relevantes e consequências. Os
estados aceitos são `Proposto`, `Aceito`, `Substituído` e `Rejeitado`.

Um ADR aceito não deve ser reescrito para esconder a decisão original. Se ela
mudar, crie um novo ADR e marque o anterior como substituído.
